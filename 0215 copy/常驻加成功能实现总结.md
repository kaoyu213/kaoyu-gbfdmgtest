# 常驻加成功能实现总结

## 功能概述

为GBF模拟器添加了常驻加成显示功能，该功能包含召唤石加成和特殊道具加成，显示效果完全参考武器盘面板的格式。

## 实现内容

### 1. HTML结构修改

在 `加成面板` 选项卡中添加了常驻加成显示区域：

```html
<div class="section-title">常驻加成</div>
<div id="resident-bonuses-output" class="bonus-box-container"></div>
```

### 2. JavaScript函数实现

#### 核心函数

1. **`renderResidentBonuses()`** - 渲染常驻加成显示
   - 获取召唤石加成数据
   - 获取特殊道具加成数据
   - 使用 `stat-line` 格式显示具体名目和数据
   - 支持分组显示和分隔线

2. **`getSummonBonuses()`** - 获取召唤石加成数据
   - 遍历所有召唤石槽位
   - 解析召唤石效果
   - 返回神石、属攻、伤害上限加成数据

3. **`getSpecialBonuses()`** - 获取特殊道具加成数据
   - 遍历所有激活的特殊道具
   - 提取道具的所有加成项目
   - 返回详细的加成数据

4. **`parseSummonEffects(summon, slotIndex)`** - 解析召唤石效果
   - 根据召唤石属性（mc则使用主手武器属性）
   - 根据槽位位置获取对应效果（主召、友召、副召）
   - 解析效果字符串，提取神石、属攻、伤害上限加成

5. **`getSummonSlotLabel(index)`** - 获取召唤石槽位标签
   - 返回对应槽位的中文标签

### 3. CSS样式

移除了不再需要的常驻加成专用样式，因为现在使用与武器盘面板相同的 `stat-line` 格式。

### 4. 集成到计算流程

在 `recalculate()` 函数中添加了 `renderResidentBonuses()` 调用，确保在每次重新计算时都更新常驻加成显示。

## 显示格式

### 召唤石加成
- **神石加成** - 显示神石加成百分比
- **属攻加成** - 显示属性攻击力加成百分比  
- **伤害上限加成** - 显示伤害上限加成百分比

### 特殊道具加成
- 显示每个激活道具的具体加成项目
- 支持多种数值类型：百分比、整数等
- 超过上限时显示 `(MAX)` 标记

### 格式特点
- 使用 `stat-line` 格式，与武器盘面板完全一致
- 左侧显示加成名目，右侧显示数值
- 数值使用 `val-highlight` 样式高亮显示
- 超过上限使用 `capped-val` 样式显示
- 不同部分之间使用分隔线分隔
