GBF 技能 / 武器 快捷新增编辑器

自动读取本目录 skills.json 与 weapons.json 做快捷联想与重复检测。
由于是静态页面（无后端），无法直接改写 json 文件 —— 请在下方生成单条对象后手动粘贴进对应 json 数组（注意上一项结尾 逗号）。
需要本地 HTTP 服务打开（如 python -m http.server），不能直接双击 file://。

粘贴说明（手动写入 json 文件）：
① 用记事本/编辑器打开 skills.json 或 weapons.json；
② 找到数组最后一个对象结尾的 }，在其后补一个 ,（若后面已经紧跟 , 则跳过）；
③ 把下方生成的单条对象（不含外层数组括号）粘贴到逗号之后、] 之前，并确认 id 不重复。
静态页面无法直接写入服务器上的 json 文件，因此采用「生成 → 复制 → 粘贴」方式。
