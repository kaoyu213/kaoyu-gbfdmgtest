奥义伤害公式：
inner = 基础伤害 × 随机补正 × 倍率 × (1+加成1) × (1+加成2) + 固定值
衰减后 + ceil = ceil( funcDecay(floor(inner), C, 衰减表) )
衰减后 + ceil → 乘被伤增幅取整 → + 伤害上升 → 乘增幅取整
最终伤害 = ceil( ( ceil( 衰减后 × (1+被伤增幅) ) + 伤害上升 ) × (1+增幅) )
先衰减，再乘增幅/被伤增幅（与 damage_cap.js 一致）
